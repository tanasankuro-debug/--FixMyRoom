# ภาคผนวก — โครงงาน FixMyRoom

เว็บแอปพลิเคชันรวมภาคผนวกของโครงงาน **FixMyRoom : ระบบแจ้งซ่อมและติดตามสถานะการซ่อมแซมอุปกรณ์ภายในห้องเรียน**
โรงเรียนเทศบาลวัดกลาง สำนักการศึกษา เทศบาลนครขอนแก่น · ปีการศึกษา 2569

พัฒนาด้วย HTML / CSS / JavaScript ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม เปิดไฟล์ `index.html` ได้ทันที

## หัวข้อภาคผนวก

| ภาคผนวก | เนื้อหา | หน้า |
|---|---|---|
| ก | แบบประเมิน (ทำแบบประเมินทีละข้อ ส่งเข้า Google Form อัตโนมัติ) | `appendix-ka.html` |
| ข | คู่มือการใช้งาน (6 แผ่น) | `appendix-kho.html` |
| ค | ภาพหน้าจอระบบ (7 ภาพ + คลิปแสดงผลบนมือถือ) | `appendix-kho2.html` |
| ง | ผลการทดสอบระบบ | *ยังไม่มีเนื้อหา* |
| จ | ผลการประเมินความพึงพอใจ (สรุปสถิติจากผู้ตอบจริง 105 คน) | `appendix-cho.html` |
| ฉ | วิธีการดำเนินงาน (FIX-IT MODEL 9 แผ่น) | `appendix-cho2.html` |

## โครงสร้างไฟล์

```
index.html              หน้าแรก รวมการ์ดภาคผนวกทั้ง 6 หัวข้อ
appendix-*.html         หน้าย่อยของแต่ละภาคผนวก
css/style.css           สไตล์ทั้งเว็บ
js/script.js            เมนูมือถือ
js/appendix-ka.js       ตรรกะแบบประเมิน + ส่งเข้า Google Form
js/appendix-cho.js      คำนวณสถิติผลการประเมิน
js/data-cho.js          ชุดข้อมูลคำตอบดิบ 105 ชุด
js/gallery.js           แกลเลอรีภาพ + กล่องดูภาพขนาดเต็ม
ภาคผนวก ข/ ค/ ฉ/        ไฟล์ภาพและวิดีโอของแต่ละภาคผนวก
```

## หมายเหตุการแก้ไข

- **เพิ่ม/แก้หัวข้อในหน้าแรก** — แก้ที่ `index.html` ตรง `.card-grid` ได้โดยตรง
- **เพิ่มคำตอบแบบประเมิน** — เพิ่มแถวใน `js/data-cho.js` แล้วตารางสถิติในภาคผนวก จ จะคำนวณใหม่ให้เอง
- **เปลี่ยน Google Form** — แก้ `FORM_ACTION` และ entry ID ทั้ง 13 ช่องใน `js/appendix-ka.js`
- เวลาแก้ไฟล์ CSS/JS ให้เพิ่มเลข `?v=` ท้ายลิงก์ในไฟล์ HTML ด้วย เพื่อไม่ให้เบราว์เซอร์ใช้ไฟล์เก่าที่ค้างในแคช
